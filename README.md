# Device Specs Detector

A simple web-based tool that detects and displays your device's specifications directly in your browser.

## ✨ Features

- 🖥️ Detect device and browser information
- 🌐 Display browser and operating system details
- 📱 Identify screen resolution and viewport dimensions
- ⚡ Show available hardware information supported by the browser
- 🔍 Display device capabilities using built-in browser APIs
- 🎨 Simple and user-friendly interface
- 🔒 No installation required

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 📊 Detected Information

Depending on browser support, the website may display:

- Operating system and platform
- Browser information
- Screen resolution
- Viewport dimensions
- Device pixel ratio
- CPU logical processor count
- Available device memory
- Touch support
- Language and timezone
- User agent information

**Note:** Browsers restrict access to certain hardware details for privacy and security. Some information may be unavailable, approximate, or reported differently across devices and browsers.
